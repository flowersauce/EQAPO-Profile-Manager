# EQAPO-Profile-Manager 设计方案

本文档是产品行为的唯一依据；实现细节见 `docs/tech-notes.md`。

## 1. 产品定位

EQAPO-Profile-Manager（命令 `eqm`）是面向 AutoEQ 与 Equalizer APO 用户的轻量配置管理器。
它负责导入、保存、列出、命名和切换 AutoEQ 生成的 Equalizer APO 配置，不生成或编辑 EQ 曲线。

项目使用 Go 实现，程序本体为无需额外运行时的 Windows 可执行文件，提供便携 ZIP、用户级 MSI 和 Microsoft Store MSIX；商店版需要通过权限审核。

软件标识：项目名称 `EQAPO-Profile-Manager`，产品简称 `EQM`，CLI 命令 `eqm`，winget PackageIdentifier 为 `Flowersauce.EQAPOProfileManager`。

## 2. 命令

```text
eqm          显示关于、当前信息和命令帮助
eqm import   (im) 导入一份 AutoEQ 配置
eqm init     (in) 设置并校验 Equalizer APO 安装根目录
eqm list     (l)  浏览所有已管理配置
eqm open     (o)  选择配置并弹出系统打开方式窗口
eqm print    (p)  选择并打印配置内容
eqm remove   (rm) 选择并删除配置
eqm rename   (rn) 选择并修改配置或目录的名称
eqm switch   (s)  选择要应用的配置
```

统一规则：

- 所有动作均不接受位置参数或 flag，包括 `--yes`。
- 所有会修改状态的命令均通过行内界面完成，不设计纯命令调用方式。
- `list` 和裸 `eqm` 只读；`list` 直接输出按名称排序的平面列表并退出，非交互时逐行输出实际文件名。
- 需要交互而当前不是终端时立即报错，不等待输入。
- 未知命令或参数必须报错，并提示运行裸 `eqm` 查看命令概览。
- 固定缩写与完整命令等价，不接受任意前缀；`show` 已移除，只支持 `print` / `p`，帮助按完整命令首字母排序。
- 默认只隐藏 `.txt` 后缀，其他后缀保留；显示名冲突时展示完整文件名。非交互列表保留实际文件名。

## 3. 管理目录

EQ 配置管理目录固定位于 Equalizer APO 的 config 目录下：

```text
<APO 根目录>\config\
├── config.txt
└── eqm-profiles\
    ├── philips-shp9500.txt
    ├── moondrop-aria-2
    └── another-profile.cfg
```

只扫描管理目录根部的普通文件，纳入合法名称且内容满足当前 GraphicEQ / ParametricEQ 识别规则的配置；忽略子目录，不跟随符号链接或重解析点，不维护索引或分类元数据。文件名不区分大小写，列表按名称稳定排序。旧分类目录及文件保留，可从原位置重新导入根目录。

当前选择以 `config.txt` 托管区域的 Include 为准，不另存一份当前状态。

启动时先检测 MSIX 包身份；商店版使用原用户 `%LOCALAPPDATA%\Packages\<PFN>\LocalState\EQM\config.json`。无包身份时检测 `eqm.exe` 同目录下的 `portable.flag`：

- 存在：便携模式，设置使用 `<exe 目录>\config\config.json`。
- 不存在：安装模式，设置使用 `%LOCALAPPDATA%\EQM\config.json`。

便携标记只由发布流程生成，不提交源码仓库。设置记录安装根目录与格式版本；解析路径不创建文件，首次 `init` 提交前不写设置。两种模式都不因权限问题静默切换配置位置，不自动迁移旧目录；EQ 文件均存放在 APO 的 `config\eqm-profiles` 中。

安装版由 WiX MSI 以 per-user 方式安装到 `%LOCALAPPDATA%\Programs\EQM`，不要求管理员权限。MSI 安装 exe、注册卸载信息、追加当前用户 PATH；普通安装与 winget 卸载均移除对应 PATH 项并递归删除 `%LOCALAPPDATA%\EQM`。Store 卸载由 Windows 清理包的 LocalState；所有安装版升级保留设置，卸载不修改 APO 的 config 目录。程序文件和安装版用户配置必须分离。

程序首次运行和 `init` 不修改 PATH；MSI / winget 管理当前用户 PATH，不创建开始菜单快捷方式。MSIX 使用系统执行别名 `eqm.exe`，以 `AppListEntry="none"` 隐藏开始菜单应用入口；卸载随包移除别名。所有安装版均不修改系统 PATH。

## 4. 初始化

`eqm init` 每次运行都重新校验并设置 Equalizer APO 位置。

### 4.1 唯一输入

用户只指定 **Equalizer APO 安装根目录**，例如：

```text
C:\Program Files\EqualizerAPO
```

程序固定使用 `<安装根目录>\config`。当前配置中的安装根目录优先作为默认值；首次运行使用 `C:\Program Files\EqualizerAPO`。进入步骤时输入值为空，默认值仅作为浅灰色 Placeholder 显示；清空输入后恢复占位提示。空输入按 Enter 使用默认值并提交，Tab 将默认值填入供编辑；输入其他路径时不附加到默认值后。

提交后立即校验：

- 安装根目录存在且是目录；
- `config` 子目录存在；
- `config.txt` 已存在，或可在 `config` 子目录内创建；
- APO config 目录可写。

确认前只进行不写文件的检查；实际创建、写入与替换能力在用户确认后验证。一般检查或写入失败时在当前步骤说明原因；权限不足时按 §12 进入 UAC 流程。

Windows 路径按 Unicode 处理，中文及其他非 ASCII 字符是受支持的正常路径，不警告、不拒绝。
`Esc` 或 `Ctrl+C` 取消整个初始化，在确认接管之前不写入任何文件。

### 4.2 接管 `config.txt`

如果 `config.txt` 尚未由 eqm 管理，`init` 必须先说明行为，并询问用户是否同意；危险操作默认选择“否”。

用户同意后：

1. 在文件开头插入由 eqm 管理的区域；
2. 用清晰的注释分隔线标出该区域；
3. 在管理区域内加入指向 `eqm-profiles\<文件名>` 的 Include；文件无需后缀。首次接管默认使用 `None`，不自动选择已有配置；
4. 保留原有内容，但逐行注释，使其暂时失效；
5. 管理区域与原内容之间保留空行和清晰的文本标题。

目标形态：

```text
# ------------------------------------------------------------
# EQAPO-Profile-Manager BEGIN
Include: eqm-profiles\philips-shp9500.txt
# EQAPO-Profile-Manager END
# ------------------------------------------------------------

# Original config.txt
# Preamp: -6 dB
# Include: example.txt
# ...
```

原有内容没有被删除，恢复时可以人工去掉每行的 `# ` 前缀。若文件已经由 eqm 管理，重新初始化只更新管理区域，不重复嵌套原内容。

上例展示已选择配置后的形态。首次初始化尚无选择时，管理区域使用 `# Include:` 表示 `None`。文件不存在时，同样先确认创建与接管，再创建空的原内容区域。

同一安装目录重新初始化时保留有效选择；更换安装目录时使用目标目录自身的托管状态，不搬迁配置、不修改旧目录。管理标记不完整、重复或含义不明确时停止修改并报错，不猜测并覆盖原文。

## 5. 配置切换与 `None`

switch 列表第一项固定为 `None`，表示不应用任何 EQ 配置。界面、状态页和输出统一使用 `None`。
选择 `None` 时，不创建额外的虚拟配置，只把 Include 行注释掉：

```text
# Include: eqm-profiles\philips-shp9500.txt
```

除 `None` 外，`switch` 只更新托管区域的 Include 路径，并保证该行未被注释。已经是当前项时成功返回，无需重写文件。

## 6. 导入

`eqm import` 始终进入路径输入步骤，路径可以手输、粘贴或从资源管理器拖入终端。

- 一次只接受一个文件；多个文件明确报错。
- 支持 AutoEQ 的 GraphicEQ 与 ParametricEQ，应该进行简单的文件内容关键字匹配检查，判定不符则拒绝。
- 不修改文件内容。
- 源文件无需特定后缀，内容仍限当前支持的 UTF-8 GraphicEQ / ParametricEQ；目标保留源文件名及后缀，不生成 slug。
- 路径校验后直接导入管理目录，不增加分类选择步骤。
- 如果目标文件名与已有配置重名，询问“是否覆盖”；默认选择“否”。
- 选择“是”后原位替换已有配置，保留已有文件名及其大小写。
- 选择“否”或取消时终止导入，不创建另一份带编号的配置，也不进入重命名分支。
- 导入完成后不自动应用。
- 导入成功应询问用户是否删除原文件，默认“否”。

覆盖正在使用的配置会更新其 EQ 内容，但不改变当前选择。导入源与目标是同一文件时拒绝操作，避免覆盖或清理自身。删除源文件失败时说明“导入已完成，源文件未删除”；在删除源文件步骤取消也不撤销已完成的导入。

## 7. 列出、查看、打开、改名和删除

- `switch`：平面列表包含 `None` 和全部配置，标记当前项并默认选中；`Enter` 应用，`Esc` 取消。
- `list`：直接输出平面配置列表并退出，不显示标题或启动选择向导；终端中使用灰色 `├ / └` 展示同级条目，末项或唯一项用 `└`，名称使用默认文本色，不增加当前项标记或底部说明。非交互时逐行输出实际文件名。
- `print`：选择配置文件后将原始内容打印到 stdout。
- `open`：列出所有配置，回车后直接弹出 Windows“打开方式”窗口，由用户选择应用。窗口返回后统一提示“已显示打开方式窗口”，不判断用户是否选择了应用；不增加动作菜单或定位目录快捷键，不修改 APO 托管状态，不自动提升外部应用的权限。
- `rename`：只选择配置文件，保留原后缀；重名时拒绝并留在输入步骤、清空输入。
- `remove`：只选择配置文件，删除前必须确认且默认否；删除当前文件前先切换到 `None`。

改名当前配置时同步更新 Include；`None` 下的注释引用也更新，保持禁用。仅改大小写允许；名称不得为空、包含路径或 Windows 非法文件名，`None` 为保留名。文件输入框只编辑主文件名，后缀由程序保留；无后缀文件保持无后缀。

终端中的 `list` 示例：

```text
├ Moondrop Aria 2 GraphicEq
└ Philips SHP9500 GraphicEq
```

无配置时，`switch` 仍提供 `None`；其他没有可执行对象的选择命令输出简短空列表结果。除裸 `eqm` 和 `init` 外，未初始化时返回错误并提示先运行 `eqm init`；裸 `eqm` 正常显示未初始化状态和命令概览。

## 8. 自愈

自愈不打扰用户：

- 裸 `eqm` 和 `list` 保持只读；当前引用的文件已丢失时，状态按 `None` 展示，不写文件、不输出重复警告。
- 修改状态的命令在用户提交操作后、执行变更前，将失效配置的 Include 静默注释；`print` 和 `open` 不承担修复写入。文件被用户移动后不追踪新位置。
- 取消且尚未提交修改时不触发修复。权限错误、读取失败、托管区损坏不属于“文件丢失”，应明确报错。

## 9. 行内 UI 设计要求

整体风格借鉴 GitHub CLI 的向导：已完成步骤压缩成整齐的一行并保留在滚动记录中，只有当前步骤保持可交互状态。

### 9.1 基本形态

```text
❯ eqm init
✓ 请输入 Equalizer APO 安装目录 C:\Program Files\EqualizerAPO
? 允许 eqm 接管 config.txt 吗？
  是
> 否
```

输入和选择标题独占一行，补充提示使用独立的 `^` 行，再显示控件：

```text
❯ eqm import
> 请输入想要导入的 AutoEQ 文件路径
: D:\Downloads\Philips SHP9500 GraphicEq.txt

❯ eqm switch
? 选择要应用的配置
    None
>   Moondrop Aria 2 GraphicEq
  ✓ Philips SHP9500 GraphicEq
```

`>` 表示正在浏览的选项，`✓` 表示实际已应用的配置，移动光标不改变已应用标记。标记使用独立列，无色模式仍可区分。

排版规则：

- 符号统一为 `✓` 完成、`?` 确认/选择、`>` 输入、`:` 输入值、`^` 提示、`!` 警告、`✗` 错误、`├ / └` 同级展示条目（末项或唯一项用 `└`）；选择步骤按选项列表识别，确认步骤显式标记，不依据文案猜测类型。
- 已完成步骤保留为单行：`✓ 问题 答案`，问题弱化，答案使用辅助色。
- 当前选择列表放在问题下一行，选中项使用 `> `，未选项使用两个空格。
- 当前文本输入独占一行，以 `: ` 开头；补充说明位于标题与输入之间，光标随提示行数定位。初始化、导入和改名共享此布局。
- 补充说明和底部按键帮助均以 `^ ` 开头；处理中状态属于提示。取消和拒绝提权使用黄色 `!`，校验/系统错误使用红色 `✗`。
- 步骤间不插入多余空行；同一向导的步骤标记、选项标记和文本起始列保持对齐。
- 不使用边框、卡片、全屏模式、动画或大面积颜色。
- 青色用于选中项与焦点光标，紫色用于输入标记和答案，绿色用于已应用与成功，黄色用于警告或取消，红色用于错误，灰色用于帮助和次要标签。列表使用平面布局，选中项的颜色优先于已应用项颜色，`✓` 始终保留已应用状态。

重命名输入示例：

```text
✓ 选择要重命名的配置 Philips SHP9500 GraphicEq
> 输入新文件名称
^ 无需输入文件后缀
: Philips SHP9500 GraphicEq
^ Enter 提交 · Esc 取消
```

### 9.2 生命周期

- 当前步骤可以局部重绘，但不能擦除已经完成的步骤。
- 提交当前步骤后，将动态区域替换为一行静态完成态，再进入下一步。
- 校验失败时只更新当前步骤下方的错误行，保留用户输入并让其修改；`rename` 重名是例外，按 §7 清空输入。
- `Esc` 或 `Ctrl+C` 取消时移除当前未完成的动态区域，已完成步骤可以保留，最后追加一行简短的取消结果。
- 操作完成后追加一行结果，不重新打印整份摘要。

### 9.3 控件

- 选择列表支持 `↑`、`↓`、`j`、`k`、`Enter`、`Esc`。
- 选择菜单使用 ↑/↓ 或 j/k 移动焦点，Enter 执行当前命令，Esc 取消；不提供目录展开或折叠。
- 确认也是两项选择列表，不接受隐藏的 `y` / `n` 快捷键。
- 危险操作默认停在 `No`；可撤销且低风险的设置可默认停在 `Yes`。
- 路径输入支持 Windows Unicode、空格、粘贴、拖拽和 Tab 补全。光标在末尾时显示浅灰色行内候选后缀，Tab 接受补全，Enter 提交实际输入（init 留空时采用默认路径）；预览不写入输入值。无色模式用方括号区分候选后缀。
- stdout 不是终端或设置 `NO_COLOR` 时不输出颜色控制码。
- 颜色仅使用终端 ANSI 调色板，不写死 RGB。

### 9.4 实现约束

- UI 层提供统一的向导运行器，管理步骤编号、完成态和当前动态区域；CLI 不应逐次启动彼此独立的完整 UI 程序。
- 输入、选择和确认共享同一套提示、缩进、错误和完成态渲染规则。
- 业务校验由 CLI/core 返回结构化结果，UI 不包含文件管理规则。
- 终端宽度变化不能造成自动换行后擦除错位；所有动态行按显示列宽截断或重排。
- 对完成态快照、当前态按键、校验错误和取消清理编写模型测试。

### 9.5 裸 `eqm` 概览页

此页定位为“关于 + 信息 + 帮助”，开头显示 `👋 Hi <username>!`，空行后显示“关于”。用户名读取当前 Windows 账户名（不含域名前缀），读取失败时显示 `👋 Hi!`；不使用用户显示名，不额外着色。各分区标题独占一行，区内条目使用 `├`，最后一项使用 `└`，分区之间保留一个空行。标签和值之间使用 `·`，标签按终端显示列宽对齐。

```text
👋 Hi <username>!

关于
├ 版本 · 1.1.0
├ 作者 · flowersauce
└ 仓库 · https://github.com/flowersauce/EQAPO-Profile-Manager

信息
├ 当前配置     · None
├ 配置数量     · 2
└ EqualizerAPO · D:\APP\Tools\EqualizerAPO

帮助
├ eqm import · 导入 EQ 配置文件
├ eqm init   · 初始化 EQM
├ eqm list   · 列出所有已导入的 EQ 配置文件
├ eqm open   · 使用 "Windows '打开方式'" 选择应用打开所选 EQ 配置文件
├ eqm print  · 选择并打印 EQ 配置文件内容
├ eqm remove · 选择并删除 EQ 配置文件
├ eqm rename · 选择并修改 EQ 配置文件名称
└ eqm switch · 选择并应用 EQ 配置文件
```

- 关于：版本、作者、仓库地址；当前版本为 `1.1.0`，发布时可在构建阶段指定。MSIX 清单身份版本为 `1.1.0.0`，程序显示及产物文件名仍使用三段版本。
- 信息：当前配置、配置数量、`EqualizerAPO` 安装路径；不展示程序设置路径和配置管理目录。当前配置直接显示名称或 `None`，不额外添加状态符号。
- 设置缺失、APO 尚未接管或已保存的目标目录/必需文件不存在时，裸 `eqm` 正常返回，信息区只显示一条 `└ 尚未初始化，请运行 eqm init。`，关于和帮助仍完整展示。
- 帮助：八个子命令及用途说明，顺序如上例。说明列统一使用 `·` 分隔；缩写直接在完整命令中按字母顺序高亮，例如 `import` 中的 `im`、`remove` 中不连续的 `r` 和 `m`，不增加括号、连接符或独立缩写列，不显示高亮含义提示。
- 标题使用默认文字色并加粗；灰色仅用于树形符号和分隔符。信息标签、信息值（含当前配置名称和 `None`）、`eqm` 前缀及帮助说明使用终端默认文字色。仓库链接使用蓝色，子命令使用默认文字色且不加粗，仅缩写字母使用青色、加粗并加下划线；未初始化提示使用黄色，错误使用红色。交互菜单保留青色焦点和绿色已应用状态。`NO_COLOR` 或重定向时保留排版和符号，不输出颜色或下划线控制码，并在帮助底部以文字列出完整缩写映射。

## 10. 文案与安全原则

1. 覆盖或修改用户现有文件前明确说明并确认。
2. 不删除原有 `config.txt` 内容，而是可视化地隔离并注释禁用。
3. 默认保留导入源文件，导入内容原样保存。
4. 非交互环境绝不等待键盘输入。
5. 能在当前步骤发现的问题立即反馈。
6. 配置丢失时静默回到 `None`，不制造重复警告。
7. Windows 支持的 Unicode 路径均视为正常输入。

## 11. 首版边界与失败反馈

首版只支持 UTF-8（可带 BOM）的 AutoEQ 文件及待接管 `config.txt`；不支持的内容编码在修改前拒绝，不能损失性转换。路径本身仍完整支持 Windows Unicode。

跨文件操作失败时说明已经完成的部分，不声称整体成功或保证全部回滚。导入完成后的源文件清理是独立动作；改名、删除和初始化的提交顺序及失败处理见实现备注。

界面根据 Windows 当前用户的系统显示语言自动切换：中文使用简体中文，英文使用英文，其他语言或探测失败时回退英文。`None` 和命令名保持原样，首版不提供手动语言切换参数。

写入 Equalizer APO `config.txt` 的程序生成注释、标题与托管标记始终使用简洁英文，不随界面语言变化。原配置内容与 Unicode 文件名原样保留，不翻译或改写。

## 12. 按需权限提升

EQM 默认以普通权限运行。已确认的提交操作遇到访问拒绝或缺少所需特权时，请求 Windows UAC，并以隐藏窗口方式启动自身的管理员工作进程。原终端保留整个向导，输入、选择、确认及结果均不转移到其他窗口；UAC 通过后继续当前提交，无需重新走流程。

管理员进程仅执行原终端发送的已确认业务操作，不运行交互向导。保留原始命令参数、工作目录、原用户配置位置和语言；同一命令复用工作进程，命令结束后退出。提交前重新核对确认时的文件身份和内容，UAC 等待期间出现外部修改则停止并提示冲突。

拒绝 UAC 后显示黄色取消提示并立即结束当前命令，退出码为 `2`；已提权仍受限时停止，不循环提权。已部分完成的事务不自动重放；通信中断且结果未知时提示先检查状态。非交互环境不等待输入或弹 UAC。初始化之前的读取、校验错误仍在原终端反馈。

安装 EQM 本身不提权，程序不默认要求管理员权限。安装、发布和权限验收细节见 `docs/windows-release.md`。

MSIX 保留相同按需提权行为，声明 `runFullTrust` 和 `allowElevation`；后者必须申请商店审批，不能以开源身份或打包成功代替审批。商店标识、打包及权限申请见 `packaging/msix/README.md`。公开 ZIP / MSI / 校验文件位于 `output/public`，商店 MSIX 位于 `output/store`。发布脚本允许同版本重新构建，全部打包成功后替换 `output`，只保留本次产物；失败保留上一份完整产物。WinGet YAML 另行生成到 `output/winget-manifests`，生成器拒绝覆盖已有版本目录。
