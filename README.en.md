## Features

- **Import profiles**: manage Equalizer APO `.txt` files with GraphicEQ or parametric EQ settings, including profiles generated by AutoEQ.
- **Switch quickly**: select and apply a profile, or disable EQ whenever needed.
- **Manage your collection**: view contents, choose an application to open a profile, rename files, or delete them.
- **Simple interaction**: arrow-key menus, Tab path completion, and Chinese or English selected from your system language.
- **Flexible setup**: installer and portable editions, with no additional runtime required.

EQM manages existing profiles; it does not generate equalizer settings. Imports currently support GraphicEQ and common parametric EQ profiles; complex configurations using Include, convolution, or other directives are not supported.

### Commands

| Command      | Action                                  |
| ------------ | --------------------------------------- |
| `eqm`        | Show version, current status, and help  |
| `eqm init`   | Set the Equalizer APO folder            |
| `eqm import` | Import a profile                        |
| `eqm switch` | Switch or disable profiles              |
| `eqm list`   | List all profiles                       |
| `eqm show`   | View profile contents                   |
| `eqm open`   | Choose an application to open a profile |
| `eqm rename` | Rename a profile                        |
| `eqm remove` | Delete a profile                        |

## Getting started

### Download and install

First, install and configure **Equalizer APO**, and prepare a compatible `.txt` equalizer profile.

Need a profile to try? Visit [AutoEQ](https://autoeq.app/), find your headphones, and export an Equalizer APO profile to use with EQM.

**[Download the latest release](https://github.com/flowersauce/EQAPO-Profile-Manager/releases/latest)** and choose:

| Edition                 | Getting started                                                                                                                   |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Installer `.msi`        | Run the installer, then open a new terminal and run `eqm`. Installation needs no administrator privileges.                        |
| Portable `portable.zip` | Extract the archive, open a terminal in the `EQM` folder, and run `.\eqm.exe`. Keep the entire folder, including `portable.flag`. |

### Apply a profile

```powershell
eqm init
eqm import
eqm switch
```

1. **Initialize**: select the Equalizer APO installation folder and confirm that EQM can manage its configuration. Press Enter to accept the suggested default path.
2. **Import**: enter the path to your profile. Tab completes paths.
3. **Switch**: select your imported profile to apply it, or choose `None` to disable EQ.

For the portable edition, replace `eqm` with `.\eqm.exe`. Use the arrow keys to select, Enter to confirm, and Esc to cancel.

Initialization preserves the original `config.txt` content as comments, so its previous settings become inactive. Read the confirmation prompt before proceeding. Changes to protected folders request administrator approval while keeping your interaction in the current terminal.

## Build

Install Go 1.25 or later on Windows, then run:

```powershell
git clone https://github.com/flowersauce/EQAPO-Profile-Manager.git
cd EQAPO-Profile-Manager
go build -o eqm.exe ./cmd/eqm
.\eqm.exe
```

A directly built executable stores settings in `%LOCALAPPDATA%\EQM`. For portable mode, create an empty `portable.flag` file next to the executable.

To produce an MSI installer and portable ZIP, also install PowerShell 7 and a .NET SDK / runtime capable of running WiX 6:

```powershell
.\scripts\build-release.ps1 -Version 1.0.0 -MsiVersion 1.0.0
```

The script restores the repository's pinned WiX tool and writes packages and SHA256 checksums to `dist`. Existing files with the same names are not overwritten.
