# 宣传素材字体

`FloriInputUI-Medium.ttf` 原样复制自用户指定的 Flori-Input 项目，用于统一宣传素材的字体。内部字体名为 `FloriInputUI`，样式为 Medium；西文字形来自 Jura，中文字形来自 Sarasa UI SC。

来源记录：`Flori-Input/resources/fonts/FloriInputUI-Medium.ttf`。该派生字体沿用 SIL Open Font License 1.1，随附两份原始版权声明及完整许可：

- `Jura-OFL.txt`
- `Sarasa-Gothic-LICENSE.txt`

字体仅用于制作本目录宣传图，当前不参与 EQM 应用构建或安装包。
